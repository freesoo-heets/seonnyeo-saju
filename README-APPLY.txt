선녀사주 Design System v2.0 패치

적용 방법
1) ZIP 압축 해제
2) 프로젝트 루트 C:\dev\seonnyeo-saju 에 app, components 폴더를 병합/덮어쓰기
3) 기존 프로젝트 전체 폴더를 삭제하지 마세요.
4) DB 변경은 없습니다.
5) 적용 후 PowerShell에서 npm run build 실행

주요 개선
- 전역 컬러/그림자/카드/버튼/폼 디자인 토큰 재정리
- 브랜드 달+별 심볼 BrandMark 공통 컴포넌트 추가
- 홈 상단을 반투명 Top Bar 형태로 개선
- 로그인/회원홈/상담신청/상담내역/상세/결과/관리자 화면의 브랜드 일관성 강화
- 빈 아이콘 영역 제거 및 실제 브랜드 심볼/기호로 교체
- 상담 신청 폼의 카드/선택 버튼/완료 화면 정돈
- 결과 PIN 화면 및 관리자 상세 화면의 구형 흰색 카드 디자인 통일
- 회원관리/관리자 상담목록 카드 대비와 가독성 개선
- PWA 설치 버튼의 비어 있던 아이콘 수정
- 모바일 카드 라운드/버튼 높이/컨테이너 폭 최적화
- prefers-reduced-motion 접근성 대응 추가

검증
- 수정된 TS/TSX 파일 15개 TypeScript transpile syntax check 통과
- 실제 프로젝트 전체 빌드는 사용자 환경에서 npm run build 로 최종 확인 필요
